
## Publicar en GitHub Pages

1. En GitHub crea un repositorio nuevo llamado `arquitectura-mqtt` (público).
2. Sube los cuatro archivos manteniendo la carpeta `assets`: **Add file → Upload files**, arrastra el contenido de esta carpeta y pulsa **Commit changes**.
3. Ve a **Settings → Pages**. En *Build and deployment* elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`, y pulsa **Save**.
4. Espera uno o dos minutos. La página quedará en:
   `https://alexpanozo27.github.io/arquitectura-mqtt/`

## Probar en tu computadora

Abre `index.html` con doble clic. Las tipografías vienen de Google Fonts, así que necesitas internet para verlas como en la versión publicada.
